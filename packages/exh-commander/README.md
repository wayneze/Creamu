# Creamu · ExH

产物：[`dist/creamu-exh.user.js`](dist/creamu-exh.user.js)

适配 E-Hentai / ExHentai，统一列表、预览、详情与控制台：

- 柔和灰米色主题，封面半透明标签；灰框已读、金框心动、绿框在库、红框断点。网格增加横向 18px、纵向 22px 间距，搜索区与追更条收紧留白。
- 原站顶部改为紧凑搜索工具栏：分类默认收起，按钮显示排除的分类数；高级搜索和文件搜索仍使用原站入口。关闭浅色主题恢复原排布及原表单状态。
- 搜索结果数与分页合为一栏，范围跳转改为细刻度；保留原站跳页弹窗、范围链接和列表模式切换。
- 列表使用全部可用宽度，网格列宽随页面与停靠控制台自适应，封面等比缩放；标题、分类／日期和底部操作依次对齐；完整原站标签可展开，关闭主题恢复原标签结构。紧凑列表的标记放在标题区，不挂到隐藏的原站预览窗。
- 悬浮预览展示作品标题和整齐内页网格，雪碧图按比例缩小；支持移入操作、Esc 关闭和窄屏内部滚动，保留跳过封面及请求取消逻辑。
- 详情页统一灰米色：封面、标题、资料、标签和下载入口自适应排布；本地库与线上版本并排对照。常用操作与快捷追更直接展示，绑定／检查来源／合并／抛弃收进「管理此作品」，刷新保留展开状态。
- 卡片保留「设为断点」，最佳版、绑定 LRR、屏蔽／取消屏蔽收在「更多」。
- 控制台宽屏默认并排停靠，顶栏可切换自由浮窗并记住位置；窄屏为底部面板。追更与作品库仍可随时呼出比对。
- 设置在控制台内打开，Esc 返回，再按 Esc 收起。设置 → 界面可关闭柔和浅色主题；已有外观选择会保留。

## 构建与验证

在仓库根目录执行：

```bash
npm run build:exh
npm run check
node tests/e2e/exh-layout.mjs
```

浏览器环境与共享控制台测试入口见[仓库开发说明](../../README.md#验证)。
