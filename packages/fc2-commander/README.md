# Creamu · FC2 Live

FC2 Live 的直播列表与观看页增强脚本。产物：[creamu-fc2.user.js](dist/creamu-fc2.user.js)。

## 列表与控制台

- 普通区 / 成人区采用深色珊瑚红主题、自适应网格，支持舒适 / 紧凑密度。
- 按标题、主播名、私人备注和标签搜索；按分类、费用、节目类型筛选，按观看人数或开播时间排序。
- 关注、屏蔽、备注、标签与最近访问保存在本机。关注项显示珊瑚色边框，访问区分「本场已看」和「曾访问」。
- 封面、标题与主播名在新标签页打开直播。顶部或右下角「控制台」可查看关注、最近访问和黑名单，不打断当前播放。
- 控制台支持搜索、在线筛选、状态刷新与取消屏蔽；桌面可并排停靠或拖动、缩放浮窗，窄屏使用底部面板。
- 顶部「原站」切回原布局，也可从原布局恢复 Creamu。

在线状态是进入列表、首次打开控制台或手动刷新时读取的快照。普通区 / 成人区可分别查询；未出现在当前区域结果中的房间显示「状态未确认」，不推断离线。请求失败保留本地记录和上次结果，不提供关闭页面后的开播提醒。

## 单房间观看

视频位于简介前，聊天支持收起、调整宽度和影院布局；窄屏聊天位于视频下方。页面资料、评论与原生弹窗使用统一暗色。

增强播放器提供播放 / 暂停、音量记忆、画中画、截图、网页全屏与全屏；原站支持时可调整画质、直播延迟、画面适配、弹幕与礼物动画。空格播放 / 暂停，上下方向键调音量，M 静音，F 全屏，W 网页全屏；输入聊天时不触发快捷键。

播放器接管原站的同一个视频节点，保留聊天、权限提示及原站取流、鉴权、画质与重连流程。「原生播放器」可随时切回并记住选择。状态显示区分加载、暂停、断网与停帧；停帧提示不等于主播已下播。

## 多路同屏

顶部「同屏」在新标签页打开观看台。输入房间 URL / ID，或从控制台加入关注与最近访问中的房间；路数可随时增减。默认根据窗口选择铺满一屏的排列，也可指定 1–4 列，房间顺序与排列方式保存在本机。

- 拖动每格左上角「⠿」调整顺序；聚焦手柄后可用方向键、Home / End 排序，Escape 取消。
- 每路可重载、移除、打开原房间或选择「听这路」。默认全部静音，同一时间只让选中的一路出声。
- 「更多 → 多路画质」可独立设置画质，或批量选择最低码率 / 自动；档位来自实际播放列表。
- 布局与排序不重建现有连接；每路独立管理连接和 HLS 引擎，移除、重载或退出会释放对应资源。

多路同屏只加载原站提供的 HLS，不加载房间聊天或礼物。需要浏览器支持 MediaSource；缺少播放源、双向直播或权限受限时，使用「打开原房间」处理。

网络和媒体错误最多自动重试三次；恢复播放后重置重试次数。主动暂停或等待自动播放许可不触发停帧重连。登录、点数、观看票与身份确认等原站拒绝会显示原因，不自动购买或绕过权限。同一房间在多个标签页重复连接可能被原站断开。

## 数据与依赖

「设置」提供 JSON 导出 / 合并导入与 WebDAV，默认远端文件为 `/Creamu/fc2.vault.json`。连接信息留在本机，不进入导出或云端数据。

播放器通过油猴 `@require` 加载固定版本的 ArtPlayer 5.4.0（MIT）和 HLS.js 1.7.4（Apache-2.0），开发测试使用同版本 npm 依赖。截图受浏览器跨域限制；YouTube 等内嵌播放器沿用站点显示。

## 构建与验证

在仓库根目录执行：

```bash
npm run build:fc2
npm run check
node tests/e2e/fc2.mjs
```

浏览器环境见[仓库开发说明](../../README.md#验证)。本地回归使用 fixtures、模拟频道 / 控制连接 / HLS 响应，以及实际媒体解码，覆盖列表、控制台、播放器接管、多路增删排序、画质、错误恢复、全屏与资源释放。模拟响应不能证明真实 HLS 分片或付费权限兼容。

0.5.1 曾完成三分钟真实六路播放及增删验收，另验证播放列表故障后的恢复；尚未完成整夜运行、已购票账户、实际系统休眠和浏览器油猴沙箱的完整验收。单房间仍使用原站媒体生命周期，其缓冲和重连行为与独立同屏模式不同。

源码按 `src/parts.manifest.json` 拼接：`10-state.js` 管理状态与导入，`20-site.js` 管理频道快照，`32-workbench.js` 管理控制台，`33-multiview.js` / `34-multi-player.js` 管理多路布局与播放生命周期，`35-player.js` / `40-room.js` 管理单房间播放器与布局。控制台样式、几何、交互和 WebDAV 复用 `packages/shared`。
