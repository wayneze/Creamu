# Creamu · HJ

海角的桌面与手机页面增强脚本，适配 `haijiao.com`、`haijiao2.com` 及其子域。产物：[creamu-hj.user.js](dist/creamu-hj.user.js)。

## 页面与搜索

- 首页、搜索结果、用户页与帖子详情统一使用柔和灰绿主题，调整卡片、表单、导航与窄屏排布。
- 悬浮「搜索」按钮随时打开搜索面板，不必滚回页首；支持帖子、用户、帖子标签与用户标签，并记住搜索条件。
- 移除手机版右下角的官方触控圆点，保留脚本的悬浮搜索入口。
- 处理原站落地提示的关闭与页面滚动恢复；正常登录、支付和权限弹窗保留。

## 用户页与详情

用户页「最新」栏目可选择「最新优先 / 最早优先」，使用明确的上一页、下一页翻页。最早优先从接口给出的末页开始读取，每次只加载一页；离开当前用户或切换栏目时取消旧请求，失败时可重试。

帖子详情解析正文图片与可用视频，提供视频切换和播放器。播放区域跟随当前帖子更新，避免旧请求覆盖新帖子；登录与观看权限仍由原站决定。

## 构建与验证

在仓库根目录执行：

```bash
npm run build:hj
node packages/hj-commander/scripts/test-core.mjs
node tests/e2e/hj.mjs
```

浏览器测试需要先安装 Chromium，见[仓库开发说明](../../README.md#验证)。本地场景覆盖桌面与手机版布局、悬浮搜索、分页排序、媒体切换及请求生命周期；真实登录后的搜索、排序与受限媒体仍需对应账号验收。

源码由 `src/parts.manifest.json` 拼接。站点识别在 `20-sites.js`，主题在 `25-theme.js`，媒体、搜索、排序分别在 `30-media-parser.js`、`31-search-memory.js`、`32-user-post-sorter.js`，页面生命周期由 `40-page-runtime.js` 管理。
