# Creamu · JavLibrary

JLC 适配 JavLibrary、JavBus、JavDB、AVMOO 及已配置镜像，具体站点入口以脚本元数据为准。产物：[`dist/creamu-jlc.user.js`](dist/creamu-jlc.user.js)。

## 页面与控制台

页面、影片详情和控制台使用统一的暖白主题。原站搜索与网站导航保留在页头；JavLibrary 的账号、收件夹和登录登出操作收在独立的「账号」菜单中。影片详情按封面与资料、预告与截图、磁力与字幕组织，原站控件和链接保留。

右下角「控制台」可随时呼出追更、熟人库、过滤。宽屏默认并排停靠，页面让出空间，可以一边浏览一边对照；标题栏可切回自由浮窗并拖动、缩放。窄屏使用浮窗或底部面板。Esc 从设置返回控制台，再按一次收起。

收藏与刷新在追更页；默认打开方式在「设置 → 显示」，Emby / WebDAV 同步在「设置 → 服务同步」。设置与备份继续使用现有存储。

## 卡片与偏好

影片卡片保留「设为断点」，「更多」中可心动、屏蔽、下载封面和查看截图；支持磁力的站点也保留磁力入口。标记状态直接显示，屏蔽后仍可原地取消。

不同心动标签各计 1 项（标题、分类重复命中不累加），熟人合计 1 项；至少命中 2 项自动亮金框并显示命中数。手动心动仍直接亮金框，自动命中不写入心动记录，手动屏蔽时不亮自动金框。Emby 入库绿框和追更断点红框优先，命中提示仍保留。

浏览过的影片保留灰框，封面叠加 16% 暗色蒙版，不加额外标记；蒙版位于悬浮标签下方，不影响标签操作。心动金框、Emby 绿框和追更断点红框优先于灰框，蒙版仍同时显示。

点击封面悬浮标签可复制完整名称；右键或触屏长按打开菜单，可添加到心动标签或在所有影片中隐藏，键盘聚焦后可按 Shift+F10。添加心动标签会立即更新当前页所有影片的高亮和命中数，并同步到设置，已添加的标签不会重复添加。隐藏的同名标签可在「设置 → 显示 → 已隐藏标签」恢复。悬停可查看完整名称与操作提示；标签保持紧凑尺寸，超出封面高度时可在标签区内滚动查看。隐藏只影响标签展示，不改变偏好命中与影片过滤；名单随设置备份和同步。

## 构建与验证

在仓库根目录执行：

```bash
npm run build:jlc
npm run check
node tests/e2e/jlc-layout.mjs
```

浏览器环境与共享控制台测试入口见[仓库开发说明](../../README.md#验证)。源码以 `src/parts.manifest.json` 为顺序拼接，控制台样式、几何、交互和 WebDAV 复用 `packages/shared`。
